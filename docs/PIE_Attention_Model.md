# PIE Attention Model

The PIE Attention Model determines what deserves the user's attention right now.

## Inputs

- PIE Runtime
- Mission
- Executive priorities
- Schedule Intelligence
- Evidence Fusion
- Photo Progress
- GPS Walk recommendation
- Open issues
- Safety concerns
- Report readiness

## Attention Item

An attention item includes:

- what matters now
- why it matters
- recommended action
- confidence
- next step
- user action type

## Priority Order

1. Safety concerns
2. Blocked or overdue schedule work
3. Mission blockers
4. Report or communication readiness that needs approval
5. Missing or stale evidence that requires capture
6. GPS/location uncertainty that requires correction
7. General project briefing

## Action Types

PIE only asks the user to:

- Confirm
- Capture
- Correct
- Approve
- Communicate

## Design Goal

The user should see one guided recommendation before seeing a dashboard of information.
