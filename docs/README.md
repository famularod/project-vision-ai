# Vitruvius Product Documentation

The current product documentation is:

- `VITRUVIUS_ECOS_NAMING_AND_ARCHITECTURE.md` — canonical naming,
  responsibilities, and migration rules.
- `ProjectVisionAI_ProductConstitution.md` — Vitruvius product constitution;
  the filename is temporarily retained for compatibility.
- `ECOS_CognitiveFramework.md` — ECOS Core reasoning framework and the ECOS
  Assurance boundary.
- `ECOS_DomainAdapterModel.md` — project-adapter boundary and legacy module
  compatibility.
- `ProjectVisionAI_JARVIS_QA.md` — ECOS Assurance release and quality contract;
  the filename is temporarily retained for compatibility.

Documents and paths carrying retired labels are historical or implementation
compatibility specifications. Those identifiers may describe existing module,
test, migration, validation, or storage contracts, but they are not current
product names. New product documentation must use Vitruvius and ECOS.
